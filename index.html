< UNDERGROUND KINGZ >

/// SCROLL ///

/// UGK ///

Underground Kingz — хип-хоп дуэт из Порт-Артура, Техас, сформированный в 1992 году. Bun B и Pimp C создали фундамент грязного юга: медленные, тяжёлые биты, бас, пропитанный сиропом, и лирика улиц, которую цитировали от Scarface до Jay-Z.

Они не искали мейнстрим — мейнстрим пришёл к ним. «Ridin' Dirty» 1996 года до сих пор считается одним из величайших южных альбомов всех времён.

< TWO KINGS / ONE CROWN >

BUN B

Бернард Фримен / MC / Визуальный архитектор дуэта

Голос UGK — глубокий, авторитетный, размеренный. После ухода Pimp C продолжил сольную карьеру и стал преподавать хип-хоп в Университете Райса. Активист, наставник, живая легенда Порт-Артура.

ACTIVE

PIMP C

Чад Батлер / Продюсер / MC / Душа звучания

Архитектор звука UGK. Создал фирменный «кантри-рэп» стиль: медленный грув, хьюстонский бас, вокал с хьюстонским акцентом. «Sweet James Jones» — его альтер-эго, символ хьюстонской ночи. Ушёл в 2007, но его влияние звучит в каждом южном треке.

TIMELINE

[ ХРОНОЛОГИЯ / 1992 → 2009 ]

1992

Формирование UGK в Порт-Артуре, Техас. Bun B и Pimp C объединяются.

1992

Выход «Too Hard to Swallow» — дебютный альбом на Jive Records.

1994

«Super Tight» — закрепление стиля и рост аудитории на Юге.

1996

«Ridin' Dirty» — шедевр, определивший звучание грязного юга. Без единого гостя.

1999

Pimp C осуждён и отправлен в тюрьму. Bun B держит имя UGK через фиты.

2001

«Dirty Money» — возвращение. Pimp C на свободе, дуэт жёстче и голоднее.

2005

Pimp C выходит из тюрьмы. Хьюстон ликует.

2007

«Underground Kingz» — двойной альбом, №1 в Billboard 200. «International Players Anthem» — гимн поколения.

2007

4 декабря. Pimp C найден мёртвым в отеле Mondrian, Лос-Анджелес. Ему было 33.

2009

«UGK 4 Life» — финальный альбом. Bun B завершает наследие. Посвящение Чаду Батлеру.

НАСЛЕДИЕ

< НАСЛЕДИЕ / ВЕЧНО >

UGK не просто выпускали музыку — они построили архитектуру южного хип-хопа. Их звучание — фундамент, на котором стоят Scarface, Z-Ro, Lil Wayne, Drake, Travis Scott.

Pimp C создал «кантри-рэп» стиль, который стал хьюстонским звуком. Bun B доказал, что один человек может нести наследие двоих.

Их влияние не ослабевает. Каждый трек с хьюстонским басом, каждый замедленный грув, каждый MC из Техаса — несёт в себе ДНК Underground Kingz.

«Pimp C был нашим QB. Он задал тон всему Югу.»

— Bun B

«Без UGK не было бы моего звучания. Они — фундамент.»

— Drake

«Ridin' Dirty — это Библия южного хип-хопа.»

— Scarface
